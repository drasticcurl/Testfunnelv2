## Cómo generar este output (paso a paso)

### Paso 1 — Generar todo el contenido en un solo prompt

Si vos sos el agente, generá las 18 páginas en formato markdown estructurado, página por página, listo para pegar a Gamma. Output esperado: archivo `outputs/pdfs/protocolo-7-dias-content.md`.

### Paso 2 — Pasar a Gamma App (lo hace el humano)

1. Ir a [gamma.app](https://gamma.app)
2. New presentation → Generate from text → Document
3. Pegar el contenido del .md
4. Elegir template: **Editorial / Minimal**
5. Aplicar paleta del Design System:
   - Primary: `#7A9B7E` (sage)
   - Secondary: `#E07856` (coral)
   - Background: `#FAF7F2` (cream)
   - Text: `#2D3A2E` (charcoal)
6. Tipografía: Fraunces (headings) + Inter (body)
7. Ajustar imágenes página por página (Unsplash / Pexels)
8. Export → PDF (Print Quality)

### Paso 3 — Revisión final

- Verificar que cada página esté completa
- Sin errores ortográficos
- Imágenes coherentes con la paleta
- Lista de compras imprimible OK
- Diario de síntomas claro

### Paso 4 — Crear Google Sheet "Diario de Síntomas"

1. Crear Google Sheet con la estructura de página 15
2. Hoja 1: tabla 7 días, columnas Día / Hinchazón / Energía / Movimiento / Notas
3. Hoja 2: gráficos auto (Insert Chart, line chart sobre las columnas Hinchazón y Energía)
4. Compartir → "Cualquier persona con el enlace puede ver"
5. El usuario hace File → Make a copy para usarlo

### Paso 5 — Subir a Hotmart (lo hace agente 11)

Entregables finales:
- `outputs/pdfs/protocolo-anti-hinchazon-7-dias.pdf`
- Link público a la planilla Google Sheets
