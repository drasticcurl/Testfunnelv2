# Agent 09 — PWA-PLAN

## Responsabilidad
Plan noche a noche: lista de 7 noches + detalle de cada una.

## Output
- app/pwa/plan/page.tsx — lista de las 7 noches con estado
- app/pwa/plan/[noche]/page.tsx — detalle de cada noche
- lib/pwa/plan-content.ts — contenido de cada noche (diferenciado por género)

## Las 7 Noches
1. **Reset:** Eliminación de disruptores + reset de horario
2. **Rutina:** Rutina pre-sueño 20 min personalizada
3. **Respiración:** Técnica 4-7-8 + body scan guiado
4. **Ambiente:** Luz, temperatura, ruido — checklist
5. **Alimentación:** Qué cenar, qué evitar, timing
6. **Mente:** Descarga mental escrita, protocolo anti-rumiación
7. **Consolidación:** Resumen + plan de mantenimiento

## Diferenciación por género
Cada noche tiene variantes para hombre/mujer en tips específicos.
