# Testimoniales AUGC v3 — Variantes "Señora ~55" (agua de arroz)

Set de creativos UGC para Meta, avatar **mujer ~55**, basado en el ganador validado (Testimonial 4 del doc v2, "señora de 55").

**Lógica de testeo:** cada idea = **1 mismo cuerpo de video** + **2 hooks distintos** = **2 creativos**. Solo cambia el Clip 1 (hook) para aislar qué gancho engancha mejor en frío.

**Regla de framing (clave):** el video se graba **al arranque del viaje**, no al final. En el hook la señora está **gorda de cara + ropa holgada** (que tape el cuerpo) y habla en presente, escéptica ("arranco / voy a probar / vamos a ver"). El resultado (flaca) se revela recién en el cuerpo. Nada de "tres semanas después" en el gancho.

---

## Reglas visuales fijas (pegar en TODA generación)

```
candid amateur selfie, shot on smartphone front camera, vertical 9:16,
realistic skin texture with pores and imperfections, minimal/no makeup,
natural indoor daylight, slight grain, authentic UGC look, everyday real woman (not a model)
```

**Negative (siempre):**
```
beauty filter, airbrushed, studio lighting, professional model, perfect symmetry,
extra fingers, distorted hands, watermark, text, oversharpened
```

**Identidad consistente:** misma mujer ~54-58, cara redonda/llena en el "antes", anteojos, pelo corto canoso-castaño, sin maquillaje. Mantener idéntica en todos los clips.

**Convención de clips:** `[FILMAR REAL]` = ideal grabarlo con actriz real · `[IA OK]` = se puede generar con IA.
